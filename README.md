<h1 style="color:#3A7AFE;">📊 Proyecto Final – Analítica de Recursos Humanos con Machine Learning</h1>

<p style="max-width: 750px; font-size: 16px;">
Este proyecto consiste en un pipeline completo de <strong>Machine Learning aplicado a Recursos Humanos (HR Analytics)</strong>.  
Se analiza un dataset de colaboradores con el fin de comprender patrones, desempeño, nivel de entrenamiento y calificaciones, permitiendo generar predicciones útiles para apoyar las decisiones del área de RRHH.
</p>

<hr style="width:75%;">

<h2 style="color:#3A7AFE;">🎯 Objetivo General</h2>

<p style="max-width: 700px; font-size: 16px;">
Desarrollar un modelo de Machine Learning que permita evaluar colaboradores mediante técnicas de analítica avanzada, apoyando la toma de decisiones sobre talento humano.
</p>

<h3>El proyecto permite:</h3>

<ul style="text-align:left; display:inline-block; font-size: 16px;">
  <li>📌 Identificar colaboradores con alto potencial.</li>
  <li>📌 Tomar decisiones de RRHH basadas en datos.</li>
  <li>📌 Mejorar procesos de entrenamiento y desempeño.</li>
  <li>📌 Utilizar una Web-App interactiva para realizar predicciones.</li>
</ul>

<hr style="width:75%;">

<h2 style="color:#3A7AFE;">📁 Componentes del Proyecto</h2>

<ul style="text-align:left; display:inline-block; font-size: 16px;">
  <li><strong>Notebook:</strong> Análisis exploratorio, preparación de datos, modelado y métricas.</li>
  <li><strong>Web-App:</strong> Aplicación en Streamlit para realizar predicciones.</li>
  <li><strong>Modelo entrenado:</strong> Archivo .pkl con el modelo, scaler y columnas.</li>
  <li><strong>requirements.txt:</strong> Lista de librerías necesarias.</li>
</ul>

<hr style="width:75%;">

<h2 style="color:#3A7AFE;">🚀 Cómo ejecutar este proyecto</h2>

<p style="max-width: 750px; font-size: 16px;">
Sigue los siguientes pasos en tu terminal para ejecutar correctamente la Web-App y reproducir el entorno del proyecto.
</p>

<h3>1️⃣ Crear un entorno virtual</h3>

```bash
  python -m venv .venv
```
<h3>2️⃣ Activar el entorno virtual</h3>

```bash
  .\.venv\Scripts\activate
```
<h3>3️⃣ Instalar dependencias</h3>

```bash
  pip install -r requirements.txt
```

<h3>4️⃣ Moverse a la carpeta de la App</h3>

```bash
  cd app
```

<h3>5️⃣ Ejecutar la Web-App</h3>

```bash
  streamlit run appy.py
```
